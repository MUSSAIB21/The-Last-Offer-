Before you launch

A short setup, then you are pitching.

The Windows build runs locally and uses Groq for the AI conversation layer. The first launch asks for a Groq API key, then stores it on your machine for future sessions.

1
Download the EXE from GitHub Releases.

The download button at the bottom of this page links directly to the current Windows build.

2
Get a free Groq API key.

Create one at console.groq.com/keys and paste it into the game when prompted.

3
Choose a startup and negotiate.

Use a preset scenario or enter your own startup idea, then respond to investors as they challenge your pitch.
